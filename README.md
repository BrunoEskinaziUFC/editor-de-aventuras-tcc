# editor-de-aventuras-tcc
Um editor visual de narrativas interativas não-lineares baseadas em grafos desenvolvido para o trabalho de conclusão de curso de Bruno Eskinazi. Esse trabalho foi projetado para editar os grafos das aventuras geradas pelo trabalho de Arthur Franco.

Para utilizar o editor basta baixar os arquivos e os manter juntos em uma past e executar o arquivo "main.html".
